# calcmonkey.com

The CalcMonkey website by Calc Monkey LLC — free math games (grades 1–6) and step-by-step math help (grade 7 through college).

- `index.html` — the main CalcMonkey site (Kids Jungle, Big Brain Lab, Solvers, Lab Arcade)
- `contact/index.html` — the Calc Monkey LLC contact page
- `assets/` — logos and icons
- `404.html` — page shown for broken links

Hosted on Netlify. Any change pushed to the `main` branch on GitHub is published automatically.

## How updates work

Ask Claude for a change → Claude saves it to this repository → Netlify publishes it to www.calcmonkey.com in about a minute.
